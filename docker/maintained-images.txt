# Images in ghcr.io/vantage6/infrastructure that we maintain. Because upgrading
# a federated network is challending, every final release of a supported major 
# version is maintained, not only the latest one. Supported major versions are 
# listed in SECURITY.md.
#
# Tags are derived from the registry: all final releases of the listed major
# versions (e.g. 5.0.3, no release candidates) plus the named development tags
# (uluru for 5, cotopaxi for 4). Tags that resolve to the same digest, such as
# hq and node in 5.x, are only processed once.
#
# Scan:    all derived tags are scanned for vulnerabilities.
# Rebuild: only releases from `rebuild from` onward are rebuilt on a schedule.
#          Rebuilding only helps when the base image receives fixes, i.e. for
#          releases built on a Docker Hardened Image (DHI). Releases built on
#          other bases are scan only (`-`). Mirrored images (see
#          docker/mirror-images.txt) are rebuilt by re-mirroring.
#
